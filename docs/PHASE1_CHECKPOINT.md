# Phase 1 — Scaffold checkpoint

## Branch
`feature/phase1-scaffold`

## Added
- Android application skeleton using Kotlin and Jetpack Compose.
- Web application skeleton using React, TypeScript and Vite.
- Initial navigation placeholders for Chat, Mangá, Documentos and Memória.
- Explicit UI notice that no AI model is connected yet.

## Not implemented
- Local text or image inference.
- Persistent chat history or memory.
- PDF import, OCR or document parsing.
- Model download and integrity verification.
- Synchronization, accounts or backend.
- APK, AAB, website deployment or release.

## Validation
No Android or web build was executed in this environment. Dependency resolution, Gradle compatibility, TypeScript compilation, browser behavior and POCO X6 5G runtime remain to be tested.

## Security notes
- No API keys or credentials are included.
- Android backup is disabled in the initial manifest.
- The public repository must contain no personal data, model weights, tokens or private documents.
